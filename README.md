## 轻量服务器价格差在哪？先看懂三个计费维度

同样标着 2核2G，腾讯云轻量服务器有 35、40、45、48、50、52、55、62 元/月等多个价位，差价主要来自峰值带宽、月流量包和套餐类型，CPU 和内存反而不是决定价格的那一项。

- **峰值带宽**：入门型从 2Mbps 到 12Mbps，通用型从 4Mbps 到 35Mbps，锐驰型统一给到 200Mbps。带宽越高，同配置价格越贵。
- **月流量包**：入门型从 100GB 到 2000GB，通用型从 300GB 到 8000GB，锐驰型不限流量。流量包只统计出流量，用超了按量计费。
- **系统盘**：普通套餐 40GB 到 450GB SSD，存储型直接给到 350GB 到 1000GB。
- **套餐类型**：锐驰型适合流量波动大的场景，入门型适合稳定小流量，通用型在带宽和流量之间取平衡，存储型用大硬盘换带宽。

拿 2核2G 举例：入门型 3Mbps、200GB 流量是 40 元/月，通用型 4Mbps、300GB 流量是 52 元/月，锐驰型 200Mbps、不限流量是 45 元/月。三者 CPU 内存一样，价格差在带宽、流量和系统盘。
